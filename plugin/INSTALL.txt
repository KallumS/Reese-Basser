Reese Basser — VST3 and CLAP plugins for macOS (Apple Silicon and Intel)

1. Quit your DAW.
2. Copy the plugins into your plugin folders (in Finder: Go > Go to Folder…):
     Reese Basser.vst3  ->  ~/Library/Audio/Plug-Ins/VST3/
     Reese Basser.clap  ->  ~/Library/Audio/Plug-Ins/CLAP/
   (Make the CLAP folder if it is not there.)
3. The plugins are not signed with an Apple developer certificate, so macOS
   blocks them until you clear the download flag. Open Terminal and paste:
     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Reese Basser.vst3" ~/Library/Audio/Plug-Ins/CLAP/"Reese Basser.clap"
4. Open your DAW and let it scan for new plugins.

The plugin runs the same Reese Basser you use in REAPER (the .jsfx inside it is
identical), with the same window. Every control is also a parameter your DAW
can automate.
